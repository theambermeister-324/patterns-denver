Session premise

You already know what's scary — let's make that the first jump.

Participants deploy a real AI agent against their own design system docs, tethered to a problem they named themselves. Not a demo. Not a deck. If they leave still calling this "scary," the session failed.

⚑ Morning Anchor — Say This Out Loud Before Anyone Opens a Laptop

Before anonymous cards are read, before the first prompt goes on screen — establish the container. Research on mixed-maturity rooms is clear: without this framing, advanced participants dominate and beginners disengage. Five sentences. First five minutes. Non-negotiable.

"Everything you build today is disposable. The sandbox is the point."

"There is no wrong answer to what you automate first."

"If something breaks — great. That's data."

Why it matters: Participants arrive with very different levels of confidence. This framing gives beginners permission to try things they'd otherwise be embarrassed to attempt in front of peers from Intuit and USAA. Say it out loud, not on a slide.

Room Onboarding Protocol

15-minute target. Phone = QR scanner + gallery viewer + output submitter. Laptop = sandbox. They work in parallel all afternoon.

Put these on the projector at T-0

Workshop Repo
github.com/theambermeister-324/patterns-denver
Gallery Wall

  • T−0 Both QR codes on screen before anyone sits down. Left = repo (clone this on your laptop). Right = gallery (open this on your phone, keep it open all afternoon). Don't wait for everyone to settle — it's already there when they walk in.
  • T+1 Amber says: "Scan the left code with your phone and clone it on your laptop. Scan the right code and keep the gallery open on your phone. Phone stays out all afternoon — that's how you see what the room is building."
  • T+3 Everyone runs npm install && claude simultaneously. Angie circulates to confirm everyone is in the right directory and Claude Code is launching. Amber watches from the front.
  • T+7 Run /setup. Amber says: "If your setup completed — give a thumbs up." Quick visual read on who is blocked. Angie moves to anyone without a thumb up.
  • T+10 Drop docs → run /ingest all. "Use the sample file for now if you don't have your own. You can replace it later." Triage card is already on every table. Angie handles blocks.
  • T+13 Everyone runs their first /query. Curious-but-new starting prompt on screen: "What are the documentation gaps in this design system?" First real output visible.
  • T+15 Pairing prompt on screen: "I want to see if AI can help me with ___." Everyone writes their sentence. Amber reads a few out loud (with permission). Pairing map revealed. Track-specific prompts go up. Remind the room: "When you have output worth sharing, submit it at patterns-denver-2026.netlify.app — from your phone or laptop, no git required."

⚠️ If onboarding takes more than 15 minutes

The afternoon is at risk. Don't try to fix it in the room with 14 people watching. This is why the dry run must happen by June 4. If the dry run takes more than 15 minutes, fix the config — not the protocol.

⚑ Afternoon Close — 5-Minute Knapsack Moment

After gallery submissions open. Not a pitch — a demonstration of what scale looks like. 5 minutes max, then back to the room.

Option A — Show Enable

Pull up the Enable platform live. "This is what happens when your org commits a knowledge base plus an agent workflow. We built this with Claude Code in the terminal — the same tool you've been using this afternoon."

Option B — Show the Knapsack MCP

Show the Knapsack MCP server / ingestion capability. "This is what Knapsack does at the platform layer so you don't have to rebuild this for each agent. Your design system becomes a live knowledge source."

"What you built today in a sandbox, Knapsack can make repeatable across your entire design system org."

Timing discipline: Hard stop at 5 minutes. Move to gallery submissions. The room just spent 2 hours doing real work — don't let the positioning moment crowd out the debrief energy.
What this connects: No platform competitor can claim real-world enterprise deployment proof. The room just generated it. This is the moment that makes Patterns Denver a Knapsack story, not just a workshop.
