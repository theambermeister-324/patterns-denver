Day of · Workshop guide

Getting started

Four steps. Takes about 10 minutes. Run these in order. If something breaks, see the triage section at the bottom.

Before you open your terminal — write this down
"I want to see if AI can help me with ___."
One sentence. This is your compass for the afternoon. Everything you build should serve it.
1
Clone the repo and open it
Copy the commands below into your terminal. You need to be inside the patterns-denver folder before continuing.
git clone https://github.com/theambermeister-324/patterns-denver.git
cd patterns-denver
npm install
claude
You should see the Claude Code interface open in your terminal.
2
Run setup
This checks your environment and creates the folders Claude needs. Run it once at the start of each session.
/setup
Claude will confirm setup is complete. Should take under 30 seconds.
3
Drop in your docs and ingest
Add any design system file to the raw/ folder — a component spec, a README, tokens reference, Figma export. A sample is already there if you want to start immediately.
# drop your file into raw/, then:
/ingest all
Claude reads your docs and organizes them into a knowledge base. You'll see a list of pages created.
4
Ask your first question
Start with one of the prompts below, or write your own based on the sentence you wrote down. This is the deployed agent — you're running it right now.
/query What are the documentation gaps in this design system?
Claude answers based only on your docs — no hallucination, no generic advice. Need more prompts? See the Prompt library.
Bonus: connect Knapsack optional

Add the Knapsack design system as a live reference so you can run comparison queries — "what does Knapsack have that my system lacks?" This takes 2 minutes and unlocks the bonus prompts on the Prompts page.

  1. Go to claude.ai/settings/integrations
  2. Add a new MCP server with URL: https://mcp.knapsack.cloud/mcp/demo
  3. Restart Claude Code — the Knapsack tools will be available automatically
  4. Try: /query What does Knapsack have that my system lacks?
Stuck? Check these three things first, then ask for help
Claude Code isn't opening
Type claude inside the patterns-denver folder — ask Angie if nothing happens
/query returns nothing
Run /ingest all first — wiki may be empty
npm errors during install
Raise your hand — Angie or Amber will come to you
"I don't know what to ask"
Open Prompts — or find Amber or Nate, this is the real question
Knapsack bonus prompts not working
Add MCP at claude.ai/settings/integrations, then restart Claude Code
