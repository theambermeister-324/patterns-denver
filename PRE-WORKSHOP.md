# Patterns Denver — Pre-Workshop Setup Guide
**Please complete before June 11, 2026**

---

Hey [name],

We're looking forward to seeing you at Patterns Denver on June 11. This is a hands-on afternoon — you'll be running an AI agent against real design system material with a partner. To make the most of the session, there are a few things to set up in advance.

**It takes about 10 minutes. Do this before you arrive.**

---

## What to install

### Node.js 20+
Check if you have it: `node --version`

If not: [nodejs.org/en/download](https://nodejs.org/en/download) — install the LTS version.

### Claude Code
```bash
npm install -g @anthropic-ai/claude-code
```

Verify it worked: `claude --version`

You'll need an Anthropic account to use Claude Code. If you don't have one, create it at [claude.ai](https://claude.ai) before the workshop — it takes 2 minutes.

---

## What to bring

**Devices:**
- Personal laptop (not your enterprise/work-managed device — Claude Code needs local file access that IT policies often block)
- Your phone — you'll use it to scan QR codes and submit to the gallery wall

**From your design system:**
Bring any documentation that represents your system. It doesn't need to be comprehensive — even a single page is enough to start. Good options:
- A component spec (button, modal, form field — anything with props and usage notes)
- A Figma-exported doc or a Confluence page you copy-pasted into a text file
- A README from your component library
- Release notes, a changelog, an accessibility guide
- A design token reference

If you're not sure what to bring, bring whatever feels most unfinished. That's usually the most interesting material to work with.

---

## What to expect

The afternoon is a hands-on sandbox session. You'll point a Claude Code-powered knowledge base at your design system docs and ask it real questions: What are the documentation gaps? What would a new engineer need to know that isn't in these docs? You deploy something real. No prior AI experience required.

You'll be paired with someone from a different org. You'll have one sentence to finish before the pairing begins. You'll build something together in the time you have.

---

## The mindset

This is a sandbox. Nothing you build today needs to be production-ready. There is no wrong answer to what you automate first. If something breaks — that's data, not failure. The point is to find out what's actually possible with your material, not to build a polished artifact.

Write down this sentence before you arrive:

> **"I want to see if AI can help me with ___."**

That's your compass for the afternoon.
